# Contributing to Cloudflare Index

Thank you for your interest in contributing! This repository contains an auto-generated index of all public repositories in the [Cloudflare GitHub organization](https://github.com/cloudflare), plus curated reference guides about Cloudflare's open source ecosystem.

---

## 📁 Repository Files

| File | Type | Description |
|------|------|-------------|
| `CLOUDFLARE_INDEX.md` | Auto-generated | A–Z alphabetical index of all repos |
| `CLOUDFLARE_TOPICS.md` | Auto-generated | Repos organized by technology category |
| `CLOUDFLARE_ECOSYSTEM.md` | Hand-curated | Product-to-repo mapping guide |
| `AWESOME_CLOUDFLARE.md` | Hand-curated | Community tools, frameworks, awesome lists |
| `CLOUDFLARE_MCP.md` | Hand-curated | MCP integration guide with architecture diagrams |
| `CLOUDFLARE_PRICING.md` | Hand-curated | Pricing reference for all Cloudflare services |
| `README.md` | Hand-curated | Landing page with Mermaid diagrams and navigation |
| `site/` | React app | Interactive explorer (Vite + React + TypeScript) |
| `scripts/generate_cloudflare_index.py` | Script | Regenerates the auto-generated files |

> ⚠️ Do **not** manually edit `CLOUDFLARE_INDEX.md` or `CLOUDFLARE_TOPICS.md` — they are fully regenerated by the script on every run.

---

## 🔄 How Auto-Generation Works

The `scripts/generate_cloudflare_index.py` script:
1. Fetches all public repos from `github.com/cloudflare` via the GitHub REST API
2. Sorts them alphabetically (for `CLOUDFLARE_INDEX.md`)
3. Categorizes each repo using keyword rules and explicit overrides (for `CLOUDFLARE_TOPICS.md`)
4. Writes both Markdown files

The GitHub Actions workflow (`.github/workflows/update_cloudflare_index.yml`) runs this every Monday at 06:00 UTC and can be manually triggered from the **Actions** tab.

## 🖥️ Running the Script Locally

```bash
# Clone the repo
git clone https://github.com/SpiralCloudOmega/Cloudflare_Index.git
cd Cloudflare_Index

# Generate alphabetical index only
GITHUB_TOKEN=your_token python scripts/generate_cloudflare_index.py

# Generate both index and topics
GITHUB_TOKEN=your_token python scripts/generate_cloudflare_index.py --topics

# Print JSON stats (no files written)
GITHUB_TOKEN=your_token python scripts/generate_cloudflare_index.py --json
```

> A `GITHUB_TOKEN` is strongly recommended — unauthenticated requests are rate-limited to **60/hour**; authenticated requests get **5,000/hour**.

## 🗂️ Improving Category Detection

Categories are determined by the `categorize()` function in `scripts/generate_cloudflare_index.py`.

**To fix a miscategorized repo**, add an entry to the `EXPLICIT_OVERRIDES` dict at the top of the script:

```python
EXPLICIT_OVERRIDES = {
    # ...existing entries...
    "my-repo-name": "Security & Cryptography",  # add your override
}
```

Valid category names:
- `AI & Machine Learning`
- `Workers & Serverless`
- `Security & Cryptography`
- `Networking & Infrastructure`
- `Observability & Monitoring`
- `Databases & Storage`
- `Developer Tools & SDKs`
- `Web & Frontend`
- `Documentation & Examples`
- `Libraries & Utilities`

**To improve general keyword matching**, update the keyword lists in the `categorize()` function body.

## 🗺️ Improving CLOUDFLARE_ECOSYSTEM.md

`CLOUDFLARE_ECOSYSTEM.md` is the hand-curated product guide. It maps Cloudflare products to their GitHub repos and documentation. PRs to improve this file are welcome for:

- Adding newly open-sourced repos to the right product section
- Updating docs links
- Adding new product sections as Cloudflare launches new products
- Fixing inaccurate descriptions

## 🐛 Reporting Issues

| Issue Type | What to include |
|------------|----------------|
| Miscategorized repo | Repo name + suggested category |
| Missing repo | Repo name + why you think it should be included |
| Inaccurate description | Repo name + suggested correction |
| Script bug | Error output + Python version |
| Stale star counts | Note that counts update automatically each Monday |

---

## 🔀 Pull Request Guidelines

1. Keep changes **focused** — one logical change per PR.
2. For script changes, run the script locally and verify the output looks correct.
3. For `CLOUDFLARE_ECOSYSTEM.md` changes, ensure all repo links point to `github.com/cloudflare/REPONAME`.
4. Do **not** manually edit `CLOUDFLARE_INDEX.md` or `CLOUDFLARE_TOPICS.md`.
